Nada Gurukulam — Complete Website & Portal Design Structure

Comprehensive technical and architectural specification for replicating the entire web application and portal design.

1. Core Stack & Infrastructure

  • Frontend: Next.js 16 App Router (Turbopack), React Client Components, Single-file portal architecture (frontend/app/page.js).
  • Backend: Express.js server (port 10000), modular auth middleware, direct Supabase & MongoDB connectors.
  • Database: Supabase Postgres (Relational Core: Auth, Roles, Permissions, Users, Curriculum Structure, Syllabi) + MongoDB (CMS blocks & rich content).
  • Deployment: Render (Backend) + Vercel (Frontend).

2. Visual Identity & Design Tokens

  • Primary Color: Maroon (#78281F / var(--primary))
  • Accent Color: Saffron (#D35400 / var(--accent))
  • Background: Cream / Warm White (#FDFEFE / var(--bg))
  • Surface/Card: Pure White (#FFFFFF / var(--surface))
  • Corner Radius: Two-side-rounded / 12px (var(--radius-xl))

3. Portal Shell & Dashboard Architecture

  • Sidebar Design: Full-height maroon navigation bar (nav.portal-sidebar). Includes branded logo, user avatar/profile access, and active module navigation list.
  • Collapsible Functionality: Managed via React collapsed state. Toggle button (.ndg-side-toggle) positioned outside the nav for consistent layout behavior. Uses ARIA attributes for accessibility.
  • Dashboard Overview: Unified 4-column widget grid (.ndg-widget-grid).
  • Dynamic Row-Packing: 4 units per line. Stat widgets occupy 1 unit, Section widgets occupy 2+ units (auto-filling rows).
  • User Customization: Toggleable Stat vs Section kinds in Edit Mode, persisted in Supabase (`dashboard_widgets.kind`).

4. Curriculum & Syllabus Module Structure

Layer Table / Collection Key Attributes
Program Category program_categories id, name, duration_value, duration_unit, sort_order
Discipline disciplines id, category_id, name, structure_mode (semester/yearly/monthly), year_count, semesters_per_year, period_minutes
Course courses id, discipline_id, code, name, year_label, semester_number, credits, examination_type_id
Syllabus & Modules course_syllabi, course_modules, course_module_topics Versioned syllabi, structured teaching hours, RBT levels, CO mappings, topics.
CMS Content MongoDB: curriculum_content Flexible rich text content keyed by course_${courseId}.

5. Role-Based Access Control (RBAC)

  • 7 Levels: None(0) < View(1) < Self(2) < Submits(3) < Own(4) < Manage(5) < Full(6).
  • Self-Service Profile: Sidebar username and public-header name trigger profile modal; PUT /api/me edits allowlisted fields (name, phone, designation).
  • Ragged Role Tree: user_categories and category_level_values self-referential tree supporting varying depth per branch.
