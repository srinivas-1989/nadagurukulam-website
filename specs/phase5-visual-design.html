Visual Design Specification

Phase 5: Applying the Interim Branding Guidelines to Portal Layouts.

1. Design System Application

This spec formalizes the visual application of tokens defined in CLAUDE.md §7 to all portal views.

  • Sidebar: Uses --surface background, --border separators, and --accent for active state.
  • Content Areas: Uses --bg background with --surface cards and --shadow elevation.
  • Typography: Headers Jost, Body Nunito Sans, Founder/Formal EB Garamond.

2. Layout Rules

  • No hard borders; use --border sparingly.
  • Use wave dividers (SVG) for breaking hero sections from main content.
  • Card elevation via --shadow tokens, ensuring consistent depth across light/dark modes.

3. Next Steps

Phase 6 build will directly utilize these tokens as CSS variables (SCSS or CSS Modules in the final stack) to ensure zero-effort theme syncing.
